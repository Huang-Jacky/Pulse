# Pulse

Pulse 是一款面向 macOS 的轻量级状态栏系统监控工具。

它以常驻菜单栏的方式展示核心系统指标，并在点击后提供更完整的实时详情，适合希望随时查看系统状态、同时又不想被复杂界面打扰的日常使用场景。

## 系统要求

- macOS 13 或更高版本
- 仅支持 Apple Silicon Mac
- 不支持 Intel Mac

## 功能特性

- 在状态栏展示 CPU、内存、磁盘、网络等关键指标
- 点击状态栏后查看更完整的实时详情面板
- 支持 CPU、内存、磁盘、网络四类指标的独立展示
- 内置配置页，可自由选择显示项目与采样间隔
- 提供电池状态信息与对应图标反馈

## 界面体验

- 极简状态栏展示，尽量减少空间占用
- 统一的弹出面板交互，便于快速查看详细数据
- 深色风格界面，更贴合 macOS 菜单栏使用环境
- 适合作为日常常驻的小型系统监控工具

## 适用场景

- 关注 Mac 当前运行负载
- 观察 CPU、内存、磁盘、网络的实时变化
- 在不打开大型系统工具的情况下快速查看关键数据
