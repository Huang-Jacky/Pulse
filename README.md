# Pulse

[🇨🇳 中文](README.md) · [🇬🇧 English](README_EN.md)

---

Pulse 是一款面向 macOS 的轻量级状态栏系统监控工具。

它以常驻菜单栏的方式展示核心系统指标，点击后提供完整的实时详情面板，适合希望随时掌握系统状态、又不想被复杂界面打扰的日常使用场景。

## 系统要求

- macOS 13 或更高版本
- 仅支持 Apple Silicon Mac（M1/M2/M3/M4 及后续）
- 不支持 Intel Mac

## 功能特性

### 系统监控

| 类别 | 指标 |
| --- | --- |
| **CPU** | 总占用率 · 每核占用 · 用户/系统/nice/idle 分解 · 负载 1m/5m/15m · 运行时间 · 历史趋势图 |
| **内存** | 已用/总量 · Active · Wired · Compressed · Free · Inactive · Swap 已用/总量 · Page In/Out · 压力等级 · 历史趋势图 |
| **磁盘** | 已用百分比 · 总容量/已用/可用 · 读写速率 · 累计 I/O · 已挂载卷列表 · I/O 历史图 |
| **网络** | 上下行速率 · 接口流量分解 · 累计传输 · Wi-Fi 信号/信道/PHY 模式/链路速率 · 代理检测 · VPN 识别 · 接口类型识别 · 历史趋势图 |
| **GPU** | 利用率百分比 · 型号名称 · 历史趋势图 |
| **电池** | 电量百分比 · 充电/放电状态 · 剩余时间 · 健康比 · 循环次数 · 充电器功率 · 温度 |
| **进程** | 按 CPU / 内存排序 Top 6 进程 |
| **系统信息** | macOS 版本 · 构建号 · 内核版本 · 硬件型号 · 芯片名称 · 总内存 · 核心拓扑（动态读取核类型名） · 电脑名称 · 用户名 · 硬件 UUID · 序列号 |

### 状态栏

- SF Symbols 矢量图标 + 数值显示
- 支持标准 / 紧凑两种布局模式，宽度不足时自动降级
- 网络上下行流量支持双行 / 单行切换
- 指标顺序可拖拽自定义
- 数值颜色跟随告警等级（正常/警告/严重）

### 详情面板

- 7 个标签页：CPU · GPU · 内存 · 磁盘 · 电池 · 网络 · 配置 · 系统信息
- 每个标签页包含 HeroCard 概览 + SectionCard 明细 + 历史柱状图
- CPU 堆叠柱状图 · GPU/内存单值历史图 · 网络双向柱状图 · 磁盘 I/O 柱状图
- 统一的深色风格界面

### 设置

- 指标启用/禁用开关（至少保留 1 个）
- 状态栏顺序拖拽 · 显示模式 · 网络布局
- 刷新间隔 1–30 秒可选
- 智能节能：低电量模式自动降低采样频率
- 登录启动（SMAppService）
- 中英文双语言切换，实时刷新
- 内置 GitHub 更新检查

## 架构

- **Swift 6** · SwiftUI + AppKit 混合架构
- **零外部依赖**，所有系统数据通过 Darwin / IOKit / SystemConfiguration / CoreWLAN 等底层框架直接读取
- **actor 隔离采样器**，线程安全
- **自适应刷新策略**：面板打开 1s → 电池供电 ≥3s → 低电量 ≥5s
- 全面中英文双语覆盖
